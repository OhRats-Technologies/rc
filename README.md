# [RC](https://rc.ohrats.party)

Remote control for your machines without exposing SSH.

RC includes the hosted Bun control plane and the `rc` Node/CLI for macOS and Linux.

## Install

```sh
curl -fsSL https://rc.ohrats.party/install.sh | sh
```

Sign in with `rc login`, or enroll a machine with the install command generated by RC.

## Run the server

```sh
docker build -t rc .
docker run --rm -p 3000:3000 -v rc-data:/data rc
```

Open `http://localhost:3000` to create the first account.

## Development

Requires [Bun](https://bun.sh/) and Go 1.25.

```sh
bun install
bun run dev
```

Node/CLI releases are built from `vX.Y.Z` tags by GitHub Actions and published through [GitHub Releases](../../releases/latest). The production Docker image contains only the control plane.
